Comment ça marche

1. Ouvre une discussion avec ➕.
2. Convenez d’une clé secrète en dehors de l’application, puis saisis-la via 🔑 (🎲 en génère une solide).
3. Écris : le message est chiffré avant l’envoi. Sans la clé, on ne voit qu’un message verrouillé 🔒.
4. Case « Retenir la clé » : tes messages s’affichent directement, sans ressaisie.
5. Pour répondre à un message précis : touche-le puis ↩️ Répondre (ou glisse-le vers la droite).
6. 📎 pour envoyer une photo, une vidéo (caméra intégrée, 20 s max) ou un fichier (5 Mo max). Appui long sur un message pour en sélectionner plusieurs (supprimer ou transférer).
7. Installation : bouton 📲, ou « Sur l’écran d’accueil » sur iPhone.
